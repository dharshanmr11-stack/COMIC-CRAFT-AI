# ComicCraft – AI Comic Story Creator

ComicCraft is a Generative AI web application that converts a user's story idea into a multi-panel comic story.

## Features

- AI-powered comic story generation
- Automatic story outline creation
- Multiple comic panels
- AI-generated panel images
- Narration and dialogue generation
- Comic preview interface
- PDF export support
- FastAPI backend
- Responsive web interface

## Technologies

- Python
- FastAPI
- Google Gemini
- Hugging Face
- HTML
- CSS
- JavaScript
- Pillow
- FPDF
