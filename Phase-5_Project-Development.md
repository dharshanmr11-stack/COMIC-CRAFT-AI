# PHASE 5 – PROJECT DEVELOPMENT

## Project Title
ComicCraft – AI Comic Story Creator

## 1. Development Environment

The ComicCraft project was developed using Visual Studio Code with Python, FastAPI and Generative AI technologies.

## 2. Frontend Development

A responsive web interface was developed using HTML, CSS and JavaScript.

The frontend allows the user to:

- Enter a comic story idea.
- Start comic generation.
- View the generated comic.
- Download the final PDF.

## 3. Backend Development

Python and FastAPI were used to develop the backend.

The backend manages:

- User requests
- Story generation
- Image generation
- Comic panel creation
- PDF generation

## 4. AI Story Generation

Gemini AI was integrated into the project to generate:

- Comic title
- Story outline
- Scene descriptions
- Narration
- Character dialogues

## 5. AI Image Generation

Hugging Face AI was integrated to generate images for the comic panels.

Each panel receives an individual visual prompt based on the generated story.

## 6. Comic Panel Generation

The generated images, narration and dialogues are combined to create individual comic panels.

The system generates a total of 10 panels.

## 7. PDF Generation

The completed comic panels are converted into a downloadable PDF file.

## 8. Project Workflow

User Story Idea
↓
Gemini AI Story Generation
↓
Narration and Dialogue
↓
AI Image Generation
↓
Comic Panel Creation
↓
Comic Preview
↓
PDF Export

## 9. Final Development Output

The completed application generates a 10-panel AI comic containing images, narration and character dialogues.

## 10. Conclusion

The development phase successfully combines web development, Generative AI, image generation and PDF generation to create the ComicCraft application.
